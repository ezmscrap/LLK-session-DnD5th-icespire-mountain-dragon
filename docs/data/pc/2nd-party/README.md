# キャラクタ作成とコンセプト

## ■ コンセプト
- ルールに慣れてきた頃なので、別のクラスを触ることでゲームへの理解を深める
- 特技が強すぎて低レベルだとヒューマン一強になりやすいので、他種族も特技がとれるLv4からとする

## ■ 初期レベルとクラス、種族の制限

### ◆ レベル4から？ 
Yesです。 

### ◆ 種族 / クラス
全て選択可能

### ◆ 初期の所持金とアイテムは？ 
以下のA案とB案から選択(ダンジョンマスターズガイドP38 高レベルスタートをベースに調整)

- **A案**
    - キャラクターを通常に作成後、冒険支援アプリで以下を追加
    - 追加所持金: 750gp
    - 魔法のアイテム(アンコモンx1)

- **B案**
    - キャラクターを通常に作成後、冒険支援アプリで以下を追加
    - 魔法のアイテム(アンコモンx2)
