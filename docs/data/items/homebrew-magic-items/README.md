# DMが独自に設定したマジックアイテム

## ■ ドラゴンスレイヤー
- 武器(ロングソード)/レア(要同調)
- 君はこのロングソードを用いた攻撃ロールとダメージロールに+1ボーナスを得る。
- 君がこの武器でドラゴンにヒットを与えると、そのドラゴンは3d6の[斬撃]ダメージを受ける。この武器に関して、"ドラゴン"とは、クリーチャー種別がドラゴンであるクリーチャー全てを指す。
- 君がこの武器のヒットでクリーチャーのヒット・ポイントを0にした場合、クリーチャーの魂、意志、記憶や超常的な力はこの武器に封じられる。封じられた存在を、君は任意のタイミングで解放できる。また、新たな者とこの武器が同調した際も、この武器に封じられた存在は解放される。

## ■ ホワイトドラゴンスケイルシールド
- 防具(盾)/レア(要同調)
- この盾を手に持っている間、君はACに+1ボーナスを得る。このボーナスは普通の盾がACに与えるボーナスを累積する。
- この盾を手に持っている間、君はドラゴンの"畏怖すべき存在"とブレス攻撃に対するセーヴに有利を得る。
- この盾を手に持っている間、君は[冷気]に対する抵抗を得る。

## ■ グリーンドラゴンスケイルシールド
- 防具(盾)/レア(要同調)
- この盾を手に持っている間、君はACに+1ボーナスを得る。このボーナスは普通の盾がACに与えるボーナスを累積する。
- この盾を手に持っている間、君はドラゴンの"畏怖すべき存在"とブレス攻撃に対するセーヴに有利を得る。
- この盾を手に持っている間、君は[毒]に対する抵抗を得る。

## ■ ホーン・オブ・ブラスティング+1
- その他の魔法のアイテム/ヴェリー・レア(要同調)
- 君は1回のアクションを使用してこの角笛の合い言葉を唱え、角笛を吹き鳴らすことができる。
- すると、この角笛は9m(30フィート)の円錐形の範囲に轟音を噴射する。
- この音は180m(600フィート)遠くまで聞こえる。
- 円錐形内のクリーチャーは、みな難易度15 耐久力セーヴを行わねばならない。
- 失敗したものは 6d6 [雷鳴]ダメージ を受け、1分間の間 聴覚消失 状態になる。
- 成功したものは 半分のダメージを受け、聴覚消失状態にならない。
- ガラスまたはクリスタル製のクリーチャーや物体はこのセーヴに不利がつき、 6d6 ではなく 12d6 の[雷鳴]ダメージを受ける。
- この角笛は使う度に5%の確率で爆発する。この爆発は、使用者に12d6[雷鳴]ダメージを与え、この角笛を破壊する
- 1d20 破壊確率が1/20 1d20で1が出ると自爆 ( 12d6 [雷鳴] )

## ■ ガーディアン・エンブレム+1
- その他の魔法のアイテム/ヴェリー・レア(要同調)
- 着用者に対するクリティカルヒットはすべて通常のヒットになる
- 非魔法的攻撃による[殴打][斬撃][刺突]への耐性(まるでライカンスロープのように!)

## ■ アーケイン・グリムワー・オブ・シャドウ・ステップ
- その他の魔法のアイテム/ヴェリー・レア(要同調;ウィザードのみ同調可能)
- 君はこの黒い革張りの本を手に持っている間、この本をウィザードの呪文初道具として使うことが出来、ウィザード呪文の呪文攻撃ロールとセーヴ難易度にボーナスを得る。ボーナスの値は+2である。
- この本は君の呪文書として使用できる。さらに、君が秘術回復の特徴を使う際、回復可能な呪文スロットの合計レベルは1上昇する。
- 君はこの黒い革張りの本を手に持っている間、ボーナスアクションで3m(10フィート)移動する。この移動は機会攻撃を誘発しない。この移動は障害物があってはならず、通常移動で移動できる範囲までである。

## ■ パール・オヴ・パワー+1
- その他の魔法のアイテム/レア(要同調;呪文の使い手のみ同調可能)
- このパールを持ち歩いている間、君は1回のアクションを使用してこのアイテムの合い言葉を唱えることにより、消費済みの呪文スロット1つを回復できる。
- 回復しようとする消費済みスロットが5レベル以上だった場合、4レベルのスロットが回復する。
- このパールは1回使用すると次の夜明けまで再使用できない。
