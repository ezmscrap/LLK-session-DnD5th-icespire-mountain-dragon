# 2026年05月 LLK例会 D&D 懸案に対する意見集約について
- 決定日: 2026/05/22

## ■ 決定事項
- 「大業物の使い手」と「射撃の名手」は5版で続投する
- 選択ルール「挟撃」は今後採用しない
- マジックアイテム購入ルールは購入タイミングの厳密化で対応し、ランダム入手のアイテムとの差別化をシナリオ段階で考える
- D&D 5.5版への移行、導入は日本語版が出てから

## ■ 意見

### ● 意見1. 5.5版ルールを一部採用するなら全面移行したい
- 意見1-1: 5.5版を取り入れるなら、このタイミングで移行したい
- 意見1-2: Hobby Japanが公開している5.5eのルールで出来るならありだと思う
- 意見1-3: Hobby Japanが公開しているのは特技も少なく、呪文も足りないので英語版の把握が必要な認識
- 意見1-4: 5.5版もキャラクター作成、レベルアップ内容、特技、呪文を全体的に調整し、強すぎたものなどが全体的にナーフされているのでバランスは良いと思う
- 意見1-5: 5版と5.5版の相違点が多岐、微細にわたり過ぎて、次回までに英語の5.5版を読み、相違点を把握するのは現実的ではないと思う
- 意見1-6: 英語の5.5版を各自が読んでも、翻訳タイミングでの日本語の揺れなどで同じルールとして把握することは困難である可能性が高い
- **DM見解**: 英語のままで、各種ルールブックを各自が読み通すのは現実的ではないと考えるので、今回は5版で行かせて下さい

### ● 意見2. +10以上のダメージ5連撃はやり過ぎかもしれない
- 意見2-1: 公式のルールである 5.5版ルール採用はシンプルで良いと思う
- 意見2-2: 流石に+10以上がついた5連撃はやり過ぎかもしれないと思った
- 意見2-3: AC17に5連撃が全ヒットの理由は全ての攻撃に有利がついたせいもあるので、挟撃と排他ならばありかと思う
- 意見2-4: 筋力18(+4)と+2武器とブレス(平均+2)に-5修正をつけるとAC17への命中は14以上(35%)なので有利(57.6%)でも全ヒットは6.4%、有利が無ければ0.5%なので、特異例に惹かれすぎるのは良くないと考える
- 意見2-5: 「大業物の使い手」と「射撃の名手」は強すぎてそれしか選択できなくなるのはつまらないと感じる
- 意見2-6: 1箇所に5.5採用するなら全体的なバランスを考えると全面移行した方が良いと思う → ● 意見1へ
- **DM見解**:  様子見的ではありますが、挟撃ルールの使用を止めることで様子を見させて下さい

### ● 意見3. 挟撃ルールに関して
- 意見3-1: 今後、サモンゴーレムなどでお手軽挟撃成立になり、ゲームバランスの崩壊の恐れがある
- 意見3-2: 力術系統ウィザードの呪文効果範囲操作でファイアボールが実質的に敵味方識別機能を備えているため、敵のボス以外が容易に一掃されて、実質的にPC専用のボーナスになってしまっている点がバランスを悪く感じさせている可能性がある
- 意見3-3: 簡単に有利がつくが不利をつける要素が少ないため、バーバリアンの「捨て身の攻撃」の存在意義が死んでしまう
- **DM見解**: バーバリアン参戦の件もあり、そもそもが選択ルールであったことも考え、以降、挟撃ルールを採用しないものとさせて下さい

### ● 意見4. マジックアイテム購入ルールについて
- 意見4-1: 資源である金貨が有限なので、連続購入はそもそも出来ないと考えている(ので今のままで良いのでは?)
- 意見4-2: いまの運用が甘く見えるのは、「宣言したその場で欲しいものが買えている」点が問題であり、ルール通りに、冒険開始時に依頼、冒険終了時に受け取りを正しく運用すれば問題は減ると考えている
- 意見4-3: 現在の進行感だと+1武器が買えてしまうから、ボス討伐報酬がアンコモンの武器+1だと残念に感じるのが問題と思うので、買えるアイテムとランダム入手アイテムの差別を別途考えた方が良いと思う
- **DM見解**: マジックアイテム購入ルールは購入タイミングの厳密化で対応し、ランダム入手のアイテムとの差別化をシナリオ段階で考える方向で調整させてください。
