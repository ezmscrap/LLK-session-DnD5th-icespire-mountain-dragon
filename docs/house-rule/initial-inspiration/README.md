# ハウスルール: インスピレーションはPCは全員が最初から持っている

- PCはインスピレーションを持った状態から始める。
- PCがインスピレーションを使用すると、流石にゲームマスターも存在を思い出すので、以降はルール通りに運用する。

## ■ フレーバー
「おかしいな、普段はこの決め台詞の後、天啓が下るものなんだけどな！」

決めポーズを決めながら決め台詞を言った彼は、自分のルーチンが正常に機能しないことに対して天に対して文句をつけた。
しかし、それに続いて不適な笑みを浮かべる。

「と、言うのは冗談さ！、なぜなら……天啓はすでに下っているからだ！」

彼は誘うと剣を振った。……この剣が当たるかどうかはまた別の話である。

## ■ 問題意識
主にDMがゲーム開始後、インスピレーションの存在を忘れ、配り忘れることがある。
