# ハウスルール: 高レベルスタート時の初期の所持金とアイテムをカスタマイズする

## ■ フレーバー
- 何度か冒険を行ったPCたちは、基本的には報酬を山分けすることになる。
- その結果、当初から物持ちで裕福だったものの財産は数回の冒険で大きく膨らむことはないかもしれないが、無一文だったもの財産は比率としては極めて大きく伸びる。
- しかしながら、彼らが得ている財産はほぼ等しいのだ。
- そうであるならば、クラスごとの富裕さ、清貧さは、彼ら自身のありようで表現されるべきものであり、決して腰に下げた革袋中の金貨の重さによって表現されるものでは無いのだ。

## ■ 高レベルスタート時の初期の所持金とアイテム
後述のマジックアイテムや高額の所持金により、初期アイテムの武器や防具が不要になる可能性がある。
そのため、初期の所持品をルール通り、**クラスと背景により決定する代わりに、150GPを貰っても良い**。
ただし、これは基本的にルール通りの初期所持品を貰うより有利となるので、高レベルスタートかつDMと参加プレイヤーの許可が必要なものとする。(プレイヤーズハンドブックP143 クラスごとの初期所持品 に基づき、1dを3で固定化した上、後述の■考え方に基づき調整)

### ◆ **A案**
- キャラクターを通常に作成する

### ◆ **B案**
- キャラクターを通常に作成後、冒険支援アプリで初期所持品を全て削除
- 150GP

## ■  高レベルスタート時のボーナス初期所持金とアイテム
以下のA案とB案から選択(ダンジョンマスターズガイドP38 高レベルスタートをベースに調整)

### ◆ **A案**
キャラクターを通常に作成後、冒険支援アプリで以下を追加
- 追加所持金: 750gp
- 魔法のアイテム(アンコモンx1)

### ◆ **B案**
キャラクターを通常に作成後、冒険支援アプリで以下を追加
- 魔法のアイテム(アンコモンx2)

## ■ 考え方
- プレイヤーズハンドブックP143 クラスごとの初期所持品 は、モンクやドルイドは貧しくなるように出来ている。
- これは所持品が少ないため、他の職業に比べるとバランスが悪くなると判断されたために見える
- しかし、クラスごとに初期所持品を変えることでゲームが面白くなる度合いと、ルールに細則が増える煩雑さを比べたとき、面白くなる度合いの方が小さいと判断したため、ルールの簡易化のため、全クラス一括にしている。
