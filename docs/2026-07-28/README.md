# 2026年07月 LLK例会 07/28の ガリオ・エリブロのマジックショップについて
- 決定日: 2026/07/28

## ■ フレーバー
- ガリオ・エリブロは、見込みのある客にのみスクロールを販売します。
- 基本的に、ガリオ・エリブロの依頼を一回以上、受注した彼の知人にのみ開放します。
- また、ガリオ・エリブロの依頼を3回達成すると、彼のお気に入りになります。
- なお、ガリオ・エリブロは知っている呪文を何でも教えるわけではありません。
    - 力術などは、「私の専門外だ。力任せの魔法は美しくない」と作ろうとしません。
    - 一部危険な術は、禁制目録としており、ガリオが認めた人物にしか販売しません。
