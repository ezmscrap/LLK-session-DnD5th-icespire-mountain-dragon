# 2026年07月 LLK例会 07/29の ハズ・ヨラムのポーションショップについて
- 決定日: 2026/07/29

## ■ フレーバー
- ハズ・ヨラムは、自分を助けてくれそうな人にポーションを販売します。
- 基本的に、ハズ・ヨラムの依頼を一回以上、受注した人にのみ開放します。
- それぞれのポーションは1シナリオに最大5個まで販売できます。
