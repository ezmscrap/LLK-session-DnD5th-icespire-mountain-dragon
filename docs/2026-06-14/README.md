## ■ 漏れていたハウスルール: 「インスピレーションはPCは全員が最初から持っている」

主にDMがゲーム開始後、インスピレーションの存在を忘れ、配り忘れることがある。

この問題を解決するため、PCはインスピレーションを持った状態から始める。
PCがインスピレーションを使用すると、流石にゲームマスターも存在を思い出すので、以降はルール通りに運用する。

## ■ 漏れていたハウスルール: 「インスピレーションは有利でない判定の振り直しに使用しても良い」

PCの判定で、インスピレーションの存在を忘れ、有利をつけない判定してからインスピレーションの存在を思い出すことがある。

この問題を解決するため、有利がついていなかった判定はインスピレーションを用いて1回だけ振り直すことができる。
この際、他のPCが自分のインスピレーションで自分以外のPCの振り直しのチャンスを与えることもできる。
振り直しに、さらに他のPCがインスピレーションを与えることで、振り直す際に「有利」を与えることも出来る。
