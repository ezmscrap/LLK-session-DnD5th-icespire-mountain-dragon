# 2026年06月 LLK例会 EINさん、バーバリアンのサブクラスについて大いに語る、について
- 決定日: 2026/06/06

## ■ 狂戦士の道
　いわずと知れたサブクラス、狂化の強さは海外でも高評価！でもそれを台無しにするほど消耗が重すぎるっていう評価も同様、向こうではハウスルールで対策してない場合選択しない方が無難とまで言われてて内輪の意見とほぼ同様（どんなルールかは不明）

　ボーナスアクションで攻撃できるのが単純に強い（柔軟性も高い）

## ■ トーテム戦士の道
　いわずと知れたサブクラスその２、やはりというかクマさんの硬さが唯一無二、精神以外全部耐性付きになるのは割と無法。ただどこでも硬いだけで「どうやって攻撃されるか？」が課題なようで「HIT ME!」の看板持って立ってろとか酷い言われようｗ

　また操作が自分の番に２回殴って終わりっていう単調なプレイになりがちでつまらんという意見も多い（バーバリアンなんだから仕方ないじゃん）


## ■ 祖霊戦士の道
　百科全書追加サブクラスその１、昨日は微妙と評したがどっこいバーバリアンが苦手とする「ターゲットを取る（自分を攻撃するよう仕向ける）」能力に関してフォーカスした能力を持ち（激怒して殴らないといけないけど）それができなかった場合でも祖霊の盾でダメージをカットしてかばえるとそっちに関してはパラディンとかよりよほど優秀。

　問題はダメージにかかわる能力がなく（攻防ともに）PAM( Pole Arm Master:長柄の使い手)＋GWM(Great weapon master:大業物の使い手)がほぼ基本になる（大体のバーバリアンはそうなんですがね…）

## ■ 信仰の熱狂者の道
　百科全書追加サブクラスその２、選ぶならこれか狂戦士と話に出たが、売りはターン１回の追加ダメージと１回のセービング振り直し。

　非常に汎用性が高いと評したが追加ダメージが低いと思ってたが（１D6と思ってた）実際は「１D6＋バーバリアンLVの半分」でした…、これは最大で１D6＋10まで上がるわけで各レベル帯でも二刀流のスタイル持って逆手で殴る位のダメージソースがターン一回ただでついてくる様なものだった為評価が大きく上がりました。

　また使用制限が「ターン１回」な為機会攻撃等別ターンの攻撃にも乗るためうまく立ち回るとえらいことになると思われる。

　やはりこちらもPAM＋GWMの組み合わせがマスト、上記の機会攻撃を生かすためGAM＋守護戦士も高相性（動かしてくれる見方が居ればになるが）PAMは懐に入られると機会攻撃事態はほぼ不可能になる欠点があるの

## ■ 荒ぶる魔力の道
　万物釜追加サブクラスその１、強い弱いは置いといてランダム要素がうんことの評でしたが、意外や海外では結構高評価な声が多く、曰く「ただ殴るだけじゃなくて毎回ランダムロールでいろんなこと怒って楽しいぜHehe」との事…本人楽しそうだが回りは冷めてそう、僕心配( ﾟДﾟ)

　他にはスペルスロットを回復できる珍しい能力を持っていたり、強力な魔力識別視覚を持っていたりと「受け入れる余裕がある」パーティにならまあいてもいいかもって評価は変わらない感じ。

## ■ 獣の道
　万物釜追加サブクラスその２、精査して評価が変わったサブクラスその２、昨日は良い所無しせめて武器と同時に噛みつければって評でしたが、いやいや銀鍵君の見立てた爪が強かった、片手空いてれば最大の売りである追加攻撃ができるため「二刀の使い手」と組み合わせることで逆手で２回攻撃が可能に！

　利き手にバトルアックス（ロンソでも）逆手に爪を生やして利き手で２回＋逆手で２回の４回攻撃に、また１０レベルの「怒りの伝染」によりさらに追加ダメージまたは同士討ちさせるよう仕向けたりと、バーバリアンにありがちな「レベル上げてもおもんない」が解消されてるのが◎

　しっぽも両手武器＋しっぽの組み合わせ（盾持ってもいいけど火力が死ぬ）時にリアクションで一気にACを増やせる為防戦に強くなるが上記の爪がロマンシングなのでちょっと霞むか。

　PAM＋GWMという「いつもの特技セット」ではなく「戦闘スタイルのたしなみ（なくても良い）＋二刀の使い手」と珍しい組み合わせができるのが最大のポイント、１0レベルで「戦場大混乱♪」は割とカオス（追加精神ダメージ2D12も大概だがそもそも使用制限が「肉体武器を当てた目標（見えてる必要あり）」ってだけなのは割と壊れてる感ある(習熟ボーナス回の制限は妥当か)_(:3」∠)_

## ■ 総評
　狂戦士の道はやはり消耗のリスクがでかすぎるっていうのは海外でも共通の問題な模様（ハウスルールに関してはそこまでしたくないってのが本音）

　トーテム戦士の道はクマの一言に尽きる（海外含む）、「強いが面白くない」というライダーRXの体現みたいな奴_(:3」∠)_

　祖霊戦士の道は意外やターゲットコントロールができる類の立ち回りが面白そう、祖霊の盾覚えてからが本番になるか、ただそっちに全振りしてるためバーバリアンとしては物理3属性の耐性しか持ってないため攻防で見劣りするのが課題か、良くも悪くもPTとの連携が大事、トーテムのクマと違って置物になりにくいのが高評価（クマの硬さはそれ補って余りあるが）

　信仰の熱狂者の道は固定ダメージ見落としてたのが痛恨、意外やいかにリアクションで追加で殴るか？って部分をフォーカスすると意外と楽しそう（バトルマスターのコマンダーストライクやフィアーで恐怖させる等）PT単位での連携が肝のサブクラスと再評価、火力では１，２って海外の評は正しかったと思う(/ω＼)

　獣の道、今回一番見直したサブクラス、逆手の爪で2回攻撃が熱い激怒のボーナスも最大活用できるのも〇、上記熱狂者同様制限が「ターン1回」な為爪で機会攻撃した場合2回殴れてお得、何よりPAM＋GWMから解放されるのが素敵。
　また特技を、「二刀の使い手」だけにして爪二刀流もコスパが良い(利き手で3回逆手で1回になるか)、余った特技枠で両手武器+ＧＷＭや弓+弓術の達人取ったりと特技の幅がでる。
