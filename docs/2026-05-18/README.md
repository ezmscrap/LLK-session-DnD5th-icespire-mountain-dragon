# 2026年05月 LLK例会 D&D 懸案課題について

- 参加者の意見を集めたいです。

## ■ いただいている提案:
- **提案1**: 「大業物の使い手」と「射撃の名手」を5.5版準拠にする
- **提案2**: 挟撃で有利がもらえる回数を、一人につき1ラウンドにおいて「挟んでいる人数」までにする 
- **提案3**: マジックアイテム購入はシナリオに1回とし、さらに、1回購入できたら、つぎのシナリオでは購入は1回休みにする

## ■ 提案1: 「大業物の使い手」と「射撃の名手」を5.5版準拠にする
- **問題意識**: +10ダメージを複数回攻撃＋怒濤のアクション＋挟撃により全て有利でロールすると想定以上のダメージがでてしまう
- **提案内容**:  「大業物の使い手」と「射撃の名手」を5.5版準拠にする

- 5.5版の 「大業物の使い手」 は、以下の効果となる。
```
　能力値上昇: 筋力値を1増加させます（最大20まで）。
　重武器熟練: 自分のターンに攻撃アクションの一部として「重」特性を持つ武器でクリーチャーを攻撃した場合、その武器は対象に追加ダメージを与えることができる。追加ダメージはあなたの熟練度ボーナスに等しい。
　見事な技量: 近接武器でクリティカルヒットを達成した直後、または近接武器でクリーチャーのヒットポイントを0にした直後に、ボーナスアクションとして同じ武器で1回攻撃できます。
```

- 5.5版の「射撃の名手」は、以下の効果となる。
```
「能力値上昇: 敏捷力値を1増加させ、最大20まで上げます。
　カバー無視: 武器による遠距離攻撃は、ハーフカバーとスリークォーターカバーを無視します。
　近接戦射撃: 敵から5フィート以内にいても、遠距離武器による攻撃ロールに不利な修正は適用されません。
　長距離射撃: 遠距離からの攻撃は、遠距離武器による攻撃ロールに不利な修正を課しません。」
```
- 代替案: +10ダメージは1ラウンドに1回まで。

## ■ 提案2: 挟撃で有利がもらえる回数を、一人につき1ラウンドにおいて「挟んでいる人数」までにする 
- **問題意識**: +10ダメージを複数回攻撃＋怒濤のアクション＋挟撃により全て有利でロールすると想定以上のダメージがでてしまう
- **提案内容**: 挟撃で有利がもらえる回数を、一人につき1ラウンドにおいて「挟んでいる人数」までにする 

挟撃ルールで挟撃が成立している目標への攻撃ロールに対する有利はそのままとするが、一人のPCが1ラウンドに得られる回数に上限を設ける。すなわち、二人で挟んでいる場合は2回まで、三人で挟んでいる場合は3回までとする。

- **代替案1**: 提案1を採用した場合、提案2は不要かも
- **代替案2**: 提案1を採用しない場合、挟撃ルール自体の採用を見送る

## ■ 提案3: マジックアイテム購入はシナリオに1回とし、さらに、1回購入できたら、つぎのシナリオでは購入は1回休みにする
- **問題意識**: 確定で欲しいアンコモンのマジックアイテムが購入可能な場合、ランダムで入手できるマジックアイテムは換金した方がよくなりがちで嬉しさが相対的に低下する
- **提案内容**: マジックアイテム購入はシナリオに1回とし、さらに、1回購入できたら、つぎのシナリオでは購入は1回休みにする

あれもこれもとポンポン買えると嬉しさが減る上、ランダムで得られるアイテムへの満足度の低さが大きくなる。
さらに、判定により購入できた人と連続で失敗し続ける人の差が大きくなるので、それも抑制したい。
